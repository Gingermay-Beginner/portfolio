Interaction architecture · component preview

Three entry flows.
One four-step grammar.

Each flow uses the same state sequence: Ready → Listening → Resolve → Review result. What changes is how the bar is invoked, what context it receives, and where the result returns.

State ruleListening is a voice-input state. Translate, Formalize, and Rewrite are actions chosen during Resolve — not parallel system states.
